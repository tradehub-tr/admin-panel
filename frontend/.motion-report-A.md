# Motion A: page transition, sidebar groups, optimize card (2026-10-01)

No commits, no build, no new dependencies. Media explorer and library views were not touched.

## Files
- `src/assets/scss/variables.scss`: added one token, `$d-page: 180ms`.
- `src/layouts/AppLayout.vue`: `<router-view v-slot="{ Component }"><Transition name="page" appear @leave="onPageLeave"><component :is="Component" />`.
  - Enter animates opacity 0→1 and translateY(6px)→0 over `$d-page $ease-out`.
  - Leave is instant. `onPageLeave(el, done)` calls `done()` synchronously, so the old page is removed in the same patch. There is no overlap, no `out-in` and no leave CSS.
  - There is no `:key` and no KeepAlive. A route change that only alters the query or params reuses the component and does not animate. Style block changed to `lang="scss"` so the page can use the tokens.
  - Reduced motion: `.page-enter-from { transform: none }`.
- `src/components/layout/SidePanel.vue`:
  - Group header changed from `<div>` to `<button type="button">` with `aria-expanded` and `aria-controls="panel-group-{idx}"`.
  - A closed group gets `inert`.
  - Items are wrapped in a new `.panel-group-inner`. The class names used by e2e (`.panel-group.collapsible.open`, `.panel-group-title`) are unchanged.
- `src/assets/scss/sidebar.scss`:
  - Removed the `max-height: 800px` and padding/margin transitions. Groups now collapse with `grid-template-rows` 0fr↔1fr plus opacity over `$d-pop $ease-out` (200ms).
  - `visibility` flips after the close finishes, using a delayed step.
  - The inner wrapper has `min-height: 0` and `overflow: hidden`. Vertical spacing comes from `::before`/`::after` spacers, because padding would keep its height in a 0fr row.
  - Chevron uses `transform $d-pop $ease-out`.
  - The button reset gets a 3px focus ring in `$brand-text` (`$brand-light` in dark mode).
  - Reduced motion: `transition: none`, which also clears the visibility delay that the global rule leaves in place.
- `src/components/media/MediaProductOptimizeCard.vue`: now collapsible, following the MediaSquareCard pattern.
  - A stretched `<button data-testid="mpo-toggle">` sets `aria-expanded` and `aria-controls="mpo-body"`, with an i18n aria-label.
  - Prova, Başlat and Durdur are siblings of the toggle, not children, so clicking them does not toggle the card.
  - The body (`#mpo-body`, `inert` when closed) holds the hints, warnings, errors, run table, rollback and AVIF sections. It uses the same 200ms grid-rows technique. The chevron rotates.
  - The choice is stored in `localStorage["istoc.media.optimizeAll.open"]` (`"1"`/`"0"`), read and written inside try/catch.
  - Default:
    - Open if a run is in progress, a prova finished in this session, a run was started or watched while mounted, or there is an error.
    - Otherwise follow the stored value, and stay closed if nothing is stored.
    - A new Prova, Başlat or Geri al clears an earlier manual close.
  - Touch target: the header row is at least 44px, and action buttons get `min-height: 44px` on `pointer: coarse`. Focus ring is 3px `#5a4300` on white (about 10:1). Chevron colour is `$l-text-500`.
- `src/i18n/locales/{tr,en,ru,ar}.js`: added `media.optimizeAll.toggleAria`.

## Concerns
- Route views with a multi-root or fragment template do not get the enter animation, and Vue logs a dev-only warning for them. Six actual route views are affected: ExceptionQueueView, StatusUpdateView, ManualShipmentView, ListingFormView, SuggestCertificationView, ShipmentLegsTab. Production builds are not affected.
- During the 180ms enter, the transform makes the page root the containing block for `position: fixed` children that are not teleported. A modal that is already open when the page mounts would be offset for 180ms. Modals opened by a click afterwards are fine.
- The sidebar header is now a real button, so the global `button:active` press scale (0.97) applies to it.
