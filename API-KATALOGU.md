# Admin panel API kataloğu

[Admin panelin API başvurularını aç](http://127.0.0.1:8877/?repo=admin-panel).

Çağıran dosya/satır, HTTP yöntemi, parametreler ve Frappe/tradehub_core karşılığı birlikte gösterilir. Repo filtresinden `tradehubfront` ve `tradehub_core` görünümüne geçilebilir. Swagger sekmesi ve OpenAPI/CSV dışa aktarma bulunur.

Katalog bu çalışma alanındaki üç repoyu ve yerel Docker uygulamalarını tarar; alpha ortamına kurulu değildir. Demo/mock notları ve backend karşılığı bulunamayan başvurular ayrıca gösterilir.

Başlatma, yenileme ve kapsam: [Ortak katalog açıklaması](../docs/api-catalog/README.md).
